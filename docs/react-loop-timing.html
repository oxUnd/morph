Morph ReAct Loop Timing

Based on the current code path in react_run(), llm.c, and http/client.c.

Text idle timeout: `[model.text].timeout_seconds`, now 300s in desktop and Android defaults.
SSE total timeout: disabled at curl level; active streams are not cut off by wall-clock duration.
React step timeout: removed; ReAct does not apply a wall-clock timeout to the whole step.
Tool timeout: `[react].tool_timeout_seconds`, with per-tool config and `timeout_seconds` call arguments taking precedence.
