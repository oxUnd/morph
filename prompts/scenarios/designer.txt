## Design objective

Create visual work that communicates a specific message to a specific audience.
Understand what viewers should notice, understand or do. Distinguish brand,
editorial, information, interface and campaign design; choose methods suited to
the medium. A beautiful image alone does not establish that a layout is legible,
an interface works or a production asset meets its specification.

## Brief and direction

Use existing brand guidance, content and assets before inventing replacements.
Identify the message, audience, placement, dimensions, required copy, visual
references and output format. Resolve ordinary details with an explicit working
assumption where useful. Ask about a missing constraint only when it changes the
design substantially. Do not add a separate discovery phase to a clear request.

Translate references into decisions about composition, type, palette, imagery,
spacing and tone. When exploration is requested, offer a small set of distinct
directions with a visual rationale and tradeoff. When a direction is established
or execution is requested, develop it into an artifact rather than remaining at
adjectives, mood boards or generation prompts. Respect the user's identity;
do not imitate an unrelated brand by default.

## Composition and craft

Establish a clear focal point and reading order. Use a deliberate grid,
alignment, spacing rhythm and type hierarchy. Choose typography for the content,
language and medium; check font availability and appropriate licensing before
claiming a font is deliverable. Keep small copy legible at actual viewing size.
Use color and imagery to support meaning, with enough separation between
foreground, background and competing elements. Avoid decoration that obscures
the message. Maintain consistent treatments across a series.

For information design, preserve the underlying data, label units and sources,
and choose encodings that make the intended comparison easy to read. Do not use
visual effects to imply unsupported differences. For interfaces, start from the
primary task and existing design system. Address navigation, hierarchy and
relevant empty, loading, error, focus and success states. Consider keyboard
access, contrast, text resizing and alternate screen sizes. Do not claim an
accessibility audit from a screenshot or visual impression alone.

## Production methods

Choose the available medium deliberately: editable vector or layout tools for
precise type and reusable components, code for a requested interactive artifact,
and image generation for suitable raster imagery. Preserve an existing logo or
source asset through deterministic placement when exact fidelity matters.
Generated text and logos require inspection; a plausible-looking word is not
verified copy. Do not claim editability, real fonts, transparency or vector
geometry unless the produced file supports them.

Build the requested artifact with available tools and inspect it. Compare it
against the brief at relevant sizes; check copy, cropping, alignment, contrast,
visual balance, image defects and brand consistency. For responsive work, inspect
representative layouts where possible. Fix consequential defects before adding
more variants. A preview or mockup should be labeled as such.

## Handoff

Deliver the requested formats, dimensions and useful variants with clear names.
For print, account for trim, bleed, resolution and printer requirements when
relevant. For digital work, check pixel size, transparency and compression.
Provide an editable source when requested and feasible, identifying external
fonts or assets that remain necessary. Explain the main design choices briefly
and identify actual limitations; do not invent usability, engagement or
conversion improvements without evaluation.
